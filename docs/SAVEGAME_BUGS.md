# Savegame bugs (2026-10-27)

Scope: the memory-card owner (`runtime/src/gekko/native_card.cpp`), its default selection (`runtime/src/shadow_main.cpp`)
and the IPL's card identity (`native_ipl.cpp`). NEXT_SESSION.md, OPTIMIZATION_RESULTS.md and NORTH_STAR*.md list no
open save bug. The 2026-09-05 per-page persist stall is fixed (the debounce). All repros used copies in the session
scratchpad; the user's cards, saves and SRAM under `../game` were only read. Wording options for the save screen:
SAVE_SCREEN_OPTIONS.md. Message text: SAVE_MESSAGES_GC.txt.

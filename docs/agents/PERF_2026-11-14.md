## Rules (from the user; not negotiable)

1. **Gameplay is the holy bible: bit-exact.** Every candidate passes, measured by the coordinator:
   Westopolis 316 s state `82b65d67b2e0`, PCM `c64ee7883f980f73`, `behaviour_diff.py --exact` PASS, 10 shots equal;
   Final Haunt 120 s state `996290623a0c`, PCM `fa2abc800651039e` (`wt-cs2-integrate/.build/v/gates.sh`). A change that
   moves any of them is rejected, whatever it gains. No cheating: never weaken, skip or re-baseline a test; describe
   only what ran.
2. **Gains are measured, not argued.** A/B on the same machine, same session, interleaved (ABBA), >= 5 rounds, the
   base arm the same exe or the same tree with a switch off. Report medians with ranges and how many rounds were
   faster. A claim whose ranges overlap and whose rounds are not >= 4/5 faster is "no measurable gain" and is not merged.
   The coordinator repeats the A/B in a quiet window before merging.
3. **Heat:** every build and run goes through `tools/agents/capped_run.ps1` with your slot lock (`pf-render-slot`,
   `pf-load-slot`, `pf-threads-slot`) at `-CpuPercent 10`; builds `-m:3`. Timing runs additionally hold the
   `benchmark` lock (take your slot first, then `benchmark`: see the lock-order trap in memory notes; use
   `wt-s3-integrate/.build/v/slot_bench.ps1 -Slot <slot> -Script <sh> -WorkingDirectory <dir>`), uncapped at most 50%.
   Deterministic counters (calls, bytes, owner hits, allocations) need no lock and are preferred evidence.
4. **A running game is the user playing**: before any run check `Get-Process Shadow*`; if a game the agent did not
   start runs, wait. Never stop it. Never write into `game/` (saves, cards, executables).
5. Headless runs `--headless --no-audio` (never `--headless --audio`); windowed runs only for the threads field and
   only with the game window focused (windowed end state depends on focus).
6. Candidate exes are copied to `<name>-<md5 first 8>.exe`; no shared name is overwritten.
7. Bash heredocs collapse `\\`: write C++ escapes with Edit or with Python scripts written by Write.
8. Commit as the repo's configured author; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
   No user name or home paths in repo files. Public wording: "a static recompilation made with GekkoForge".
9. Switch new behaviour behind a `GEKKO_PF_*` environment switch (default ON once proven) so the A/B can run the same
   exe with it off.

## Rounds

Round N: each agent (a) measures its field from the current tip and names where the time goes (sampled profile,
counters), (b) picks the change with the largest measured ceiling, (c) implements it behind its switch, (d) proves
exactness locally (state + PCM on Westopolis at least) and measures its gain, (e) commits and reports: commit, switch,
ceiling, A/B table, exactness evidence, what it rejected and why. The coordinator gates, re-times in a quiet window,
merges what passes into `perf/integrate`, and the next round starts from the new tip. Rounds end when a round brings
no measurable gain in any field, or after round 3. Then the coordinator runs the full gate on the tip and merges
`perf/integrate` into `agent/opt-integrate`.

Fields and metrics:

- **render:** game-thread CPU of the headless benchmark (`host.game_thread_cpu_s`, 316 s Westopolis), the render
  share from a sampled profile; windowed 720p process CPU and GPU ms per frame.
- **load:** wall ms from `--boot-stage` start to the first gameplay frame, per stage, over a fixed stage list
  (at least stg0100, stg0201, stg0301, stg0504, stg0604), and game-thread CPU spent in loads; cold-cache and
  warm-cache runs labelled.
- **threads:** windowed 720p 60 fps: process CPU minus game-thread CPU (% of a core), frame-time p50/p99/max over the
  Westopolis tape, hitch count (> 25 ms); audio underruns must stay 0.

# Native owners for ppcrecomp --native-owners: guest functions whose entry a
# runtime handler serves on EVERY call (it never declines), so the generator
# emits only a thunk to the owner and never the original body. Startup refuses
# to run recompiled code unless each one is installed. One start per line.
#
# An address inside a listed owner's extent is an OWNER ENTRY: native code
# uses it as a guest-visible entry, so it gets a thunk of its own.
